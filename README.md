# Dr. Maya Reynolds: Therapy Website

Homepage clone and redesign built for the Grow My Therapy front-end internship assignment (Stage 2). The layout follows the Conejo Valley Family Counseling homepage. The colors, copy and images are new, based on the profile of Dr. Maya Reynolds, a fictional therapist in Santa Monica, CA.

**Live site:** maya-reynolds-therapy-liart.vercel.app
**Video walkthrough:** https://www.loom.com/share/6088b39adc294f7f821cc0682aef476e

## Tech
Next.js, React, TypeScript, Tailwind CSS (theme tokens), next/font, next/image

## Run locally
Run `npm install`, then `npm run dev`, and open http://localhost:3000

## Where things live
- `lib/content.ts`: all text and image paths
- `app/globals.css`: colors, fonts and type scale (theme tokens)
- `components/`: one component per section
- `public/images/`: photos

Photos of Dr. Reynolds and her office come from her profile. The other photos are free stock images.
